# 🧠 Core Philosophy

Every prediction must be generated through:

```text
Chart Data
      ↓
Rule Evaluation
      ↓
Evidence Collection
      ↓
Confidence Scoring
      ↓
AI Reasoning
      ↓
Human Explanation
      ↓
Prediction Output
```

### ❌ Forbidden

- Random astrology text
- Hardcoded predictions
- Fake confidence scores
- Generic AI hallucinations

### ✅ Required

- Real chart calculations
- Real astrology rules
- Explainable outputs
- Traceable reasoning
